## Chess — seated WebXR game

Current handoff snapshot: 2026-10-26. Start with [projects/chess/HANDOFF.md](../../projects/chess/HANDOFF.md), then [README](../../projects/chess/README.md), [validation/status](../../projects/chess/MILESTONES.md) and [opponent asset workflow](../../assets/chess/opponent/README.md). These describe the current implementation; Git/source remain authoritative. Consolidate changes into these docs instead of appending superseded behavior paragraphs.

Buildless ES modules in `projects/chess/src/`, static entry `projects/chess/index.html`. Serve the repository root and open `/projects/chess/`; no build/install is needed. All runtime assets are local, with relative URLs for Pages. `npm run test:chess` runs Chess; root `npm test` includes it. Latest run: **188 Chess tests and the complete root suite passed**, plus `git diff --check`. No formal Quest frame-time/stereo/comfort benchmark was recorded; user visual feedback has accepted the recent direction, including blended neck weights.

`GameController` owns authoritative chess.js rules/history. Validate on a clone → lock → animate → commit → rebuild. Epochs, worker termination and cancellable motion prevent stale moves on restart/session exit. Stockfish 17.1.0 Lite single-threaded uses 300 ms searches, 16 MB hash and actual UCI Elo limiting (launcher 1350–2000 step 50, default 1500; advertised range 1320–3190). White/Black/Random preference and seated setup persist. Only the playing board rotates for Black; coordinates and world/local conversions must stay correct.

Current interaction is controller sphere proximity grab/drop or desktop dragging. Y/B opens a scene-hiding Options billboard with trigger-operated pointer rays; Save Changes or Y/B persists Evaluate Move (default Off; when On, one separate full-strength analysis cycle starts per player-turn position (static current-board score, 1000 ms MultiPV for replies, static candidate+reply endpoint scores) and caches all pieces; pickup colors legal squares by evaluation delta: red bad, white neutral, green good, saturating at three pawns; ordinary tiles while pending) and closes. Options pause board/avatar animation and cancel held input. Left on either thumbstick during a player turn opens the pointer-driven Yes/No undo modal (`UndoDialog.mjs`); Yes uses `GameController.undoLastPlayerMove()` to remove the last player move plus opponent reply, rebuild board/history/trays and advance epochs. Preserve Black's opening; no undo before the player moves. Undo backdrop/text/rays must use distinct transparent render orders (100/101/102) to prevent view-dependent disappearance. Both undo and Options hide the world while open and restore its prior visibility on close. Modal and Options exclude each other, normal input/animation pause, fresh presses are required, and restart/session exit dismisses. Normal play has no rays, table restart/promotion buttons or gold handle mesh. Fresh open-space grip outside occupied pickup columns shows six positioning arrows and moves the environment in seated axes. XR `local` space anchors once to initial eye pose/yaw; never move the camera artificially. Hidden/untracked sessions pause animation and invalid controller tracking cancels ownership. Promotion uses a floating physical tray with hover, return/cancel highlight and selected-piece glide. Captured pieces arc to side trays late in the attacker's continuous carry; do not pause the attacking arm for clearance. Geometry intersections are allowed. The move-list box and optional Show Evaluation dial are above/behind the opponent on viewer's right; the old status box is removed; game-over illustrations include the proximity-highlighted New Game button.

The live avatar is **RiggedAvatar**, loading `projects/chess/assets/opponent/manlp.glb` (34 skinned meshes / 41 deform bones). **Edit `assets/chess/opponent/ManLP-articulated.blend`** and export with its sibling `export.py`. It includes three bones per finger/two per thumb, the eleven-part HeadLP replacement, skin-colored eyes, chest→head blended neck weights and separate head-bound wire-rim glasses with no lenses. The glasses use a named brushed-silver material that the runtime preserves. A separate thick handlebar `mustache` mesh also has full head weights and a named dark-brown hair material; its generator anchors beneath the actual nose, excluding the nose-bridge mesh. `HeadLP.blend` is an unmodified source, not the directly exported model. Earlier rig generators do not reconstruct these later edits; preserve the active file and user backups. Body scale, bone names/rest transforms and weights matter. Native arm lengths (~0.273/0.237 m), closest-hand selection, torso compensation and palm-down pinch are driven at runtime. Keep the first index bone straight along the hand; thumb placement was accepted. Avoid the former redundant return arc when switching an already-resting hand.

Head gaze smoothly follows the actual moving piece center for both opponent and player-held pieces, including promotion choices. `InputController.getHeldPiece()` validates ownership; `OpponentAnimator` chooses own-move gaze first, then player gaze; `RiggedAvatar.update()` smooths the head after arm motion. Return/drop clears gaze; cancel/reset restores immediately. Preserve neck weights (chest→head smoothstep over Blender Z 0.60–0.71 m). The upper neck is tapered/recessed beneath the jaw by `refit-neck.py` (shape influence Z 0.64–0.73 m); preserve unchanged collar anchors and weights. There is **no live mouth animation**. `EyelidBlink.mjs` rotates the four existing lid meshes around matching eyeball centers (upper +0.50 rad, lower −0.16 rad); random 2.5–6.5 s intervals, 0.16–0.26 s blinks. Bind-space positions/normals preserve head skinning, no extra draws or Blender edits; pause with avatar updates and restore exact rest on reset. Show Evaluation is a separate persisted toggle (default Off): `CurrentEvaluation.mjs` scores only playable player-turn starting boards, reuses `MoveEvaluation.baselineFor()` when available and otherwise uses a separate lazy scoring worker. `EvaluationGauge.mjs` shows a red-left/white-top/green-right semicircle with a black needle clamped to ±5 pawns from the player's perspective and an inclusive ±0.1 dead zone pointing straight up; retain the old turn score while awaiting the next, then ease the needle over 0.55 s; initial unknown scores hide it. No refresh during the opponent turn or at game over. New-game reset clears the old score; Options/hidden tracking pause the easing. Optional move hints use `MoveEvaluation.mjs`, `MoveEvaluationOverlay.mjs`, and `EngineController.analyzeMoves()`; displayed delta is the static score after the candidate plus best opponent reply minus the static current-board score, from the player's perspective. EngineController.scorePosition uses NNUE eval traces, with a depth-one resolving search for checked boards. Mate/draw endpoints are explicit; missing PV replies use a depth-four child search. Static scoring/fallbacks add overhead beyond the 1000 ms reply-search budget. Hints tint existing square instances; temporary testing numbers lie on the tiles in one transparent atlas with normal piece occlusion (one extra draw); hover does not mask evaluated colors, and promotion squares use the best choice. Drops, Options and hidden tracking hide hints while preserving the single turn search/cache; position/turn changes, disabling, game epochs and session exit invalidate searches. Include White's initial turn and skip game over. With evaluation enabled, hold A/X (xr-standard index 4) to highlight the best piece from the completed endpoint-score cache in blue; either hand keeps it active, release/Options/tracking loss clears it, and no extra search runs. ProceduralAvatar/OpponentFace remain reference/tested modules; Evaluation also supplies live score helpers. EngineController.scorePosition supplies current-board and endpoint scores.
