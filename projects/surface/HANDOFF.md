## Surface

Buildless project in `projects/surface/`, using the locally bundled Three.js r180 in `shared/vendor/three-r180/`. `surface.js` renders 64 × 64 separate horizontal quads using `THREE.InstancedMesh`: each is 9 cm square, on 10 cm centers (1 cm gaps, 6.39 m overall footprint). `DEFAULTS.spacing = 0.1` and `DEFAULTS.quadFill = 0.9` in `settings.mjs` define these dimensions, adjustable live; desktop framing and VR starting distance scale with spacing. Each particle moves a whole quad vertically without tilt. Quads are solid, with no triangle outlines. Height-based blue lightness through unlit `MeshBasicMaterial` (darker below rest, lighter above, default saturation at ±0.03 m; adjustable down to ±0.01 m) and the initial VR viewpoint 1.4 m from the center are retained. Desktop drag orbits and wheel zooms; Reset clears waves and restarts the rain timer. `locomotion.mjs` provides head-directed left-stick walking (1.5 m/s) and right-stick smooth turning (60°/s) about the tracked headset, with 15% deadzone. Motion is horizontal, without collision or edge clamping; hidden/untracked XR pauses it. No manual force controls in this version. `tuning.js` creates desktop sliders/number inputs; `VRPanel.js` provides controller rays and a canvas panel 3 m away, 45° right, following rig translation/yaw independently of head-look. A/X edge presses toggle the panel (initially visible); trigger adjusts minus/plus or actions. Shared settings cover damping, spring/restoring strength, rain strength/interval, color range, spacing and fill. Pause freezes physics/rain; reset retains settings; defaults restores and unpauses. Settings are page-session only. `tests/surface-tuning.mjs` covers live parameters, pause, bounds, stability and VR ray targeting. Surface explicitly sets XR foveation to 0; the user confirmed on Quest that this fixes the lighter rectangular peripheral bands.

`simulation.mjs` uses Float32 height/velocity arrays, a 120 Hz fixed timestep, four-neighbor spring coupling, a restoring force, velocity damping, and a 12-cell damped edge band. Every three simulated seconds, one uniformly random particle anywhere on the full 64 × 64 grid, including edge cells, receives an 8 m/s downward velocity impulse. All velocity updates read the previous height state before integrating heights. Hidden/untracked XR pauses simulation; elapsed frame time is capped to prevent catch-up bursts. `tests/surface.mjs` covers drop timing, one-point impact, propagation, damping, stability, reset, and frame-rate independence; included in the root test command. The user has tested Surface on Quest and confirmed the foveation fix; no formal performance benchmark has been recorded.

Surface defaults in `settings.mjs`: damping 0.1, spring strength 10, restoring strength 0.1, rain strength 8, interval 3 s, color range 0.03 m, spacing 0.1 m, fill 0.9, unpaused.
